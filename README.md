# TAKIM · Feed mobile

Abrí la carpeta en VS Code y abrí `index.html` (con la extensión Live Server, o haciendo doble clic).

- `index.html`: estructura
- `css/styles.css`: estilos (modo claro/oscuro)
- `js/app.js`: eventos de ejemplo, filtros y botones
- `images/`: fotos de cada evento

Para editar eventos, modificá el array `events` en `js/app.js`.
